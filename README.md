# Project Pak Joni

Website pembelajaran dan pengelolaan informasi siswa.

## Progamming language
- Next.js
- TypeScript
- SQL Database
- Docker

## Cara menjalankan Proyek
1. Install dependensi dengan `npm install`.
2. Salin `.env.example` menjadi `.env.local`.
3. Isi konfigurasi lokal sesuai kebutuhan.
4. Jalankan `npm run dev`.
